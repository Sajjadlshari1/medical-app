How to read this report

Gross profit is calculated from recorded sales minus the cost recorded for the sold stock. Net profit subtracts recorded expenses. This is an estimate, not a complete accounting statement. Unsold stock purchases are not automatically treated as expenses. Taxes, returns, damaged stock and unpaid supplier invoices need separate accounting treatment.

Data Storage

This version stores data in this browser's localStorage. It does not automatically synchronize between devices. Clearing browser data or losing the device may destroy unsaved backups. For real multi-user business use, a secure database and server are needed.
